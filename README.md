# Thunder OneCloud 专属定制固件（ImmortalWrt）

基于 [Kiddin9](https://github.com/kiddin9/OpenWrt_x86-r2s-r4s) 云编译系统构建的 Thunder OneCloud 固件，专为自托管场景优化，适合运行 Home Assistant、文件管理、远程接入等轻量化服务。

## 🎯 设备适配
- 型号：Thunder OneCloud
- 架构：ARMv7 (amlogic/meson8b)

## 🚀 默认设置
- 管理地址：`http://192.168.2.2`
- SSH 端口：22（已启用 OpenSSH & Dropbear）
- 登录账号：`root`
- 密码：无（开箱即用）

## 📦 集成功能
- ✅ LuCI 中文界面 + 插件管理
- ✅ Home Assistant 插件（依赖 Docker）
- ✅ 文件管理器（FileBrowser）
- ✅ 在线插件扩展（保留 `opkg`）
